English with Miss Fatma | زاد المعرفة
صفحة كورسات مستقلة — نسخة للمعاينة
====================================

طريقة التشغيل
1. فك ضغط الملف بالكامل أولًا باستخدام Extract All.
2. افتح المجلد fatma-courses.
3. افتح index.html في Chrome أو Edge أو Firefox.
4. احتفظ بمجلد assets بجوار index.html؛ يحتوي على التصميم والبرمجة والخطوط.

الصفحة تعمل دون اتصال بالإنترنت، ودون تثبيت برامج أو تشغيل خادم.
يمكن أيضًا وضع هذا المجلد على أي استضافة ملفات ثابتة عادية.

ماذا يوجد في النسخة؟
- صفحة رئيسية باسم English with Miss Fatma.
- خمسة كورسات إنجليزية: التأسيس، القواعد، المحادثة، الفونيكس، والمفردات.
- البحث بالعربية والإنجليزية وتصفية الكورسات حسب المجال.
- تفاصيل كل كورس، أهدافه، ومحتوى دروسه.
- معاينة أول درس، وإضافة الكورس مجانًا للتجربة.
- عشرون درسًا نصيًا، مع أمثلة مترجمة وتدريب مصحح لكل درس.
- مساحة «كورساتي»، وتحديد الدروس المكتملة، ومتابعة نسبة الإنجاز.
- اختبار مبدئي من ثمانية أسئلة، مع شرح الإجابات واقتراح كورس.
- تصميم عربي RTL ونصوص إنجليزية LTR، ملائم للموبايل والتابلت والكمبيوتر.
- خط عربي محلي مرفق؛ لا يعتمد على Google Fonts أو أي اتصال خارجي.
- لا توجد لوحة أستاذة أو إدارة أو وظائف خاصة بالمدرس.

حدود النسخة التجريبية
المحتوى وأسماء الكورسات والأسعار المعروضة أمثلة قابلة للتعديل.
لا توجد مدفوعات فعلية أو حسابات مستخدمين أو قاعدة بيانات أو فيديوهات حقيقية.
إضافة الكورس هنا مجانية وتجريبية، وتفتح بقية الدروس في هذه النسخة.
محتوى الدروس نصي للتجربة. لا توجد ملفات صوتية أو فيديوهات مرفقة.
الاختبار تقييم مبدئي فقط؛ لا يحدد مستوى CEFR معتمدًا، ولا يقيس الاستماع أو التحدث.
التقدم ونتيجة الاختبار محفوظان في localStorage، عند سماح المتصفح بذلك.
الحفظ مرتبط بنفس المتصفح والجهاز والمسار/العنوان الذي فتحت منه الصفحة.
فتح الملف من مسار مختلف أو مسح بيانات المتصفح قد يُظهر تجربة جديدة.
إذا منع المتصفح الحفظ، يظهر تنبيه وتعمل التجربة في ذاكرة الصفحة مؤقتًا.
لإعادة البدء: «كورساتي» ثم «مسح التقدم التجريبي» ثم تأكيد المسح.

الملفات
index.html                 هيكل الصفحة المستقلة.
assets/styles.css          التصميم والألوان والتجاوب مع الشاشات.
assets/app.js              التصفح والبحث والدروس والاختبار وحفظ التقدم.
assets/data.js             نصوص الكورسات والدروس والأسعار والأسئلة.
assets/favicon.svg         أيقونة الصفحة.
assets/fonts/              خط Noto Sans Arabic وترخيصه.
README.txt                 التعليمات الحالية.

لتعديل المحتوى مستقبلًا
عدّل بيانات الكورسات والدروس داخل assets/data.js باستخدام محرر نصوص.
حافظ على المعرفات id للدروس والكورسات لتظل بيانات التقدم القديمة مرتبطة بها.
الهوية هنا عنوان نصي وأيقونة كتاب؛ يمكن إضافة شعار المشروع الأصلي لاحقًا.
الملف المضغوط يضم هذا القسم وحده. لم تُدمج النسخة مع المشروع الأصلي.
